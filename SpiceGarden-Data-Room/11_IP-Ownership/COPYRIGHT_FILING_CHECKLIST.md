## 1. Statutory Filing Workflow (e-Filing via `copyright.gov.in`)

| Step | Action Item | Responsible Party | Status |
| :--- | :--- | :--- | :--- |
| **Step 1** | **Account Creation:** Register applicant account on `https://copyright.gov.in` (e-Filing portal). | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 2** | **Form XIV Entry:** Fill out Form XIV, Statement of Particulars (SoP), and Statement of Further Particulars (SoFP) using data in [`COPYRIGHT_APPLICATION_DATA.md`](file:///c:/Users/mehta/Desktop/SpiceGarden/SpiceGarden-Data-Room/11_IP-Ownership/COPYRIGHT_APPLICATION_DATA.md). | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 3** | **Class Selection:** Select Class of Work: **Literary / Computer Software**. | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 4** | **Fee Payment:** Pay online statutory filing fee of **₹500** via Bharatkosh payment gateway. | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 5** | **Diary Number Issuance:** Record the generated statutory Diary Number and filing acknowledgment receipt. | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 6** | **Physical Pack Preparation:** Print 3 sets of Form XIV, SoP, SoFP, Payment Receipt, Work Description, Ownership Declaration, and Source Code Deposit (first 10 and last 10 pages). | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 7** | **Physical Dispatch:** Send physical application pack via Registered Post / Speed Post to the Copyright Office, New Delhi within 30 days of e-filing. | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 8** | **Mandatory 30-Day Waiting Period:** Monitor diary status during statutory 30-day objection window under Rule 70(9). | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 9** | **Scrutiny & Discrepancy Response:** Respond to any formal discrepancy letters issued by Examiner of Copyrights (if any). | Owner / Counsel | `USER ACTION REQUIRED` |
| **Step 10**| **Certificate Issuance:** Download the Registration Certificate (ROC extract) upon grant. | Owner / Counsel | `USER ACTION REQUIRED` |
