## 1. Search Scope and Methodology

This checklist documents the preliminary trademark availability queries conducted across key jurisdictions:

### A. Indian Trade Marks Registry (IP India)
- [x] **Class 09 Query:** Word search for "SPICEGARDEN" / "SPICE GARDEN" in Class 09 (Software). Result: Zero identical live software registrations.
- [x] **Class 39 Query:** Word search for "SPICEGARDEN" in Class 39 (Transport / Food Delivery). Result: Zero identical active delivery service marks.
- [x] **Class 42 Query:** Word search for "SPICEGARDEN" in Class 42 (SaaS / Software Services). Result: Zero identical SaaS marks.
- [x] **Class 43 Query:** Word search for "SPICEGARDEN" in Class 43 (Restaurant Services). Result: Several local physical dining establishments exist with "Spice Garden" in name; distinction required between software platform (Class 09/42) and brick-and-mortar restaurants.
- [x] **Phonetic Search:** Phonetic query on "SPICEGARDEN" / "SPYSGARDEN". Result: No deceptive phonetic conflicts in technology sector.

### B. International Databases (WIPO & US PTO TESS)
- [x] **WIPO Global Brand Database:** Preliminary check shows no conflicting international registrations under Nice Classes 09 or 42.
- [x] **USPTO TESS Query:** Clear for software and mobile application SaaS categories.

## 2. Distinction Between Preliminary Search and Legal Opinion

> [!IMPORTANT]
> A preliminary database query is NOT a formal legal guarantee of registrability. Prior to marketing in specific territories, qualified trademark counsel must issue a formal Legal Clearance Opinion and handle official examination reports.
