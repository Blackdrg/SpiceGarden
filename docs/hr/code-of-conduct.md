# Code of Conduct

**Version:** 1.0.0

## Principles
- **Respect:** Treat colleagues, customers, restaurants, and drivers with respect.
- **Integrity:** No fraud, bribery, or corruption. Report concerns via the whistleblower channel.
- **Compliance:** Follow all laws, the Acceptable Use Policy, and Security Policy.
- **Safety:** Prioritize physical and data safety.

## Prohibited
Harassment, discrimination, retaliation, insider trading, unauthorized data access, or misuse of platform position.

## Enforcement
Violations reviewed by HR + Legal; may result in coaching, suspension, or termination.
