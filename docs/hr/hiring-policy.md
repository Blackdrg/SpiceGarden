# Hiring Policy

**Version:** 1.0.0

## Process
1. Req approved by eng lead + finance.
2. Sourcing → screen → technical interview → panel → offer.
3. Background verification for roles with data/infra access (see Driver Agreement §Background Verification for the partner analog).
4. Reference checks for leadership.

## Standards
- Merit-based, non-discriminatory.
- Security training (SDLC, OWASP) in onboarding.
- Role mapped to RBAC least-privilege (`docs/security/access-control-least-privilege.md`).

## Records
Stored in HRIS; retained per Data Retention Policy.
