# Exit Policy

**Version:** 1.0.0

## On resignation/termination
1. Manager notifies IT + HR same day.
2. **Access revocation:** disable SSO, RBAC roles, VPN, infra creds within 24 h (break-glass for P1).
3. **Assets:** return laptop, badges, keys; remote-wipe BYOD container.
4. **Data:** handover; no personal retention of company/PII data.
5. **Final settlement:** per contract; outstanding dues per Finance.

## Records
Exit checklist signed; retained per Data Retention Policy.
