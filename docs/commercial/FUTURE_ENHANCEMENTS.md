# SpiceGarden — Future Enhancements Catalog

The following items represent potential post-acquisition roadmap enhancements. Under the active feature freeze, these items are deliberately excluded from the core production release candidate.

## 1. Advanced Machine Learning & AI
- Dynamic delivery ETA prediction based on live historical traffic models.
- Personalized recommendation engine for dishes and repeat orders.
- Automated menu OCR ingestion for vendor onboarding.

## 2. Platform Extensions
- gRPC microservice migration using the existing `@spicegarden/proto` and `@spicegarden/grpc-transport` foundation.
- Voice ordering integration (Siri Shortcuts / Google Assistant).
- Multi-currency automatic conversion for cross-border delivery zones.

## 3. Advanced Fleet Management
- Automated batch clustering for drivers picking up from multiple adjacent restaurants.
- In-app driver turn-by-turn navigation overlay with custom tile servers.
