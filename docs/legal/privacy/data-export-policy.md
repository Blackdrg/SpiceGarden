## 1. Right to Data Portability (GDPR Article 20 / CCPA §1798.100)

You have the right to receive a copy of your personal data in a structured, commonly used, and machine-readable format. We provide a self-service data export feature.

---

## 2. What Data Is Exported

When you request an export, the `buildExportPayload()` method (`data-subject-request.service.ts:496-524`) extracts data from all tables linked to your user ID:

| Table | Contents | Export Fields |
|-------|----------|---------------|
| `users` | Account identity | id, fullName, email, phone, createdAt, updatedAt, deletedAt |
| `orders` | Order history | id, status, paymentStatus, grandTotal, createdAt, restaurantId, branchId, deliveryAddressId, deliveredAt, otpCode |
| `order_items` | Order line items | id, orderId, menuItemId, quantity, unitPrice, totalPrice, variants, addons, tax breakdown |
| `sessions` | Active/inactive sessions | id, userId, deviceName, deviceType, ipAddress, expiresAt, isActive, createdAt, lastActiveAt |
| `audit_logs` | Activity log | id, action, performedBy, entityType, entityId, metadata, ipAddress, timestamp |
| `notifications` | Notification history | id, recipientId, notificationType, provider, status, payload, createdAt |
| `user_devices` | Registered devices | id, userId, fcmToken, apnsToken, deviceName, deviceType, userAgent, ipAddress, isActive |
| `wallets` | Wallet balance | id, userId, balance, currency, createdAt, updatedAt |
| `wallet_transactions` | Wallet transactions | id, walletId, amount, type, description, referenceId, createdAt |
| `addresses` | Saved addresses | id, userId, label, addressLine, city, state, postalCode, location, isDefault |
| `support_tickets` | Support history | id, ticketNumber, subject, category, priority, status, messages, attachments, resolutionNotes |

Total: **11 tables** (aggregated from `buildExportPayload()` which queries 9 named tables; wallet transactions and order items are included via relations).

## 3. Export Formats

Three formats are supported, generated by `generateExportContent()` (`data-subject-request.service.ts:453-494`):

| Format | Content Type | Filename Pattern |
|--------|-------------|-----------------|
| **JSON** (default) | Full structured data with all fields | `spicegarden-data-export-{userId}.json` |
| **CSV** | Flattened key-value table (`section,field,value`) | `spicegarden-data-export-{userId}.csv` |
| **PDF** | Plain text summary of sections | `spicegarden-data-export-{userId}.pdf` |

All exports include an **integrity signature** (`integrity.sign(payload)` at `data-subject-request.service.ts:521`) to verify authenticity.

---

## 4. Export Process Flow

1. **Request:** `POST /privacy/exports` with `{ userId, regulation, format, requestId? }` → `createExport()` (`data-subject-request.service.ts:389-412`) creates a `DataExportRequestEntity` record.
2. **Build:** `buildExportPayload()` queries all user tables and assembles the payload.
3. **Finalize:** `finalizeExport()` updates status to `completed` and stores `filePath` / `downloadUrl`.
4. **Notify:** User receives a notification that the export is ready.
5. **Download:** `GET /privacy/exports/:exportId/download` → `generateExportContent()` generates the file on-demand and streams it as an attachment (`privacy.controller.ts:113-127`).

**Expiration:** Export links expire 7 days after completion (`createExport()` sets `expiresAt` at `data-subject-request.service.ts:400`). List existing exports: `GET /privacy/exports/:userId`.

---

## 5. SLA

- Export requests are processed within **24 hours** (or 30 days for complex requests, per GDPR).
- You may list your exports at `GET /privacy/exports/:userId` (returns up to 50 records).
- Preview available sections at `GET /privacy/export-preview/:userId` (returns section names without data).

---

## 6. Limitations

- Maximum 1,000 records per table per export (enforced by `take: 1000` at `data-subject-request.service.ts:512`). For larger datasets, contact support.
- Exports contain all data linked to your user ID. Data linked to other users (e.g., restaurant data managed by the restaurant owner) is not included.
- Payment card numbers are never included — only tokenized references (`cardLast4`, `cardBrand`).
