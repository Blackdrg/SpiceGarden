# Support Handbook

**Version:** 1.0.0

## Channels
- In-app chat, email support@spicegarden.com, phone (per market).
- Merchant & driver support via dedicated queues.

## Tiers
| Tier | Scope | SLA |
|------|-------|-----|
| L1 | Account, order status, refunds | 1st response < 15 min (chat), < 4 h (email) |
| L2 | Technical, integration, payout | < 1 business day |
| L3 | Engineering/escapes | per Incident Response severity |

## Tools
- Ticketing integrated with user/order lookup (Customer Web / Super Admin).
- Order lifecycle visible to support for traceability.

## Escalation
- Unresolved L1 → L2 → L3 → on-call (see `docs/ops/incident-playbook.md`).
- PII access follows Privacy Policy + DPDP grievance path.
