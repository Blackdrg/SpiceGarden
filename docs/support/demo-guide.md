# Demo Guide

**Version:** 1.0.0

## Flow (10 min)
1. Customer Web: signup → MFA → browse restaurant → cart → checkout (wallet + card).
2. Restaurant Dashboard: incoming order → accept → KDS → mark ready.
3. Delivery Partner: assign → navigate → handoff.
4. Super Admin: oversight, finance, settlements, compliance center.

## Talking points
- Multi-tenant, enterprise-grade; compliance built-in (GDPR/DPDP/PCI).
- Reliability: 99.9% SLO, HPA autoscaling, chaos-tested.
- Security: defense-in-depth, MFA, full audit trail.

## Pre-reqs
- Staging deployed; demo restaurant + driver seeded; test cards.
