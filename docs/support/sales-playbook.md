# Sales Playbook

**Version:** 1.0.0 · **Status:** TEMPLATE — marketing/finance to finalize pricing & ICP.

## Ideal Customer Profile
- Restaurants (QSR + casual dining) wanting owned delivery + aggregaton.
- Enterprise food courts / cloud kitchens needing multi-tenant management.
- Logistics partners onboarding drivers at scale.

## Value props
- Multi-tenant marketplace with built-in compliance (GDPR/DPDP/PCI).
- Wallet, loyalty, subscriptions, settlements, analytics out of the box.
- Enterprise SLA + 99.9% reliability + autoscaling.

## Objection handling
- "Locked into aggregators?" → owned-channel + wallet + loyalty retention.
- "Compliance burden?" → DPDP grievance officer + consent manager + audit trail.
- "Can it scale?" → k6 10k/20k load tests, HPA, chaos-tested.
