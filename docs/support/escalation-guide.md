# Escalation Guide

**Version:** 1.0.0

## Ladder
L1 Support → L2 Technical → L3 Engineering → On-call SRE → Engineering Manager → CTO.

## Triggers
- SLA breach on a case → next tier.
- Suspected fraud/security → Security Incident Response (bypass ladder).
- Data breach → DPO + Legal immediately (GDPR 72h).

## Handoff
- Document repro, user impact, steps tried.
- Use the incident/escalation record in Super Admin.
