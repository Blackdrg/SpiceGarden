# Support SOP

**Version:** 1.0.0

## Common cases
1. **Missing/wrong order** — verify order status; if undelivered, initiate refund per Refund Policy; wallet credit option.
2. **Late delivery** — check ETA vs actual; weather/traffic excluded; offer goodwill per policy.
3. **Payment failed but charged** — verify gateway; refund via original method (5–10 business days) or wallet.
4. **Account lock** — verify identity; MFA reset with step-up.
5. **Merchant onboarding block** — check KYC/FSSAI/bank; resubmit.
6. **Driver payout query** — verify cycle + incentives; raise to L2.

## Refund authority
- L1: standard refunds within policy.
- Exceptions → L2 + Finance.
- Never bypass audit logging.

## Privacy requests
- Access/delete/correct → Privacy Dashboard or privacy@spicegarden.com; L3 handles per DPDP/GDPR.
