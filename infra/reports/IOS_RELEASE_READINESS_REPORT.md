## IPA Generation Procedure

Once external dependencies are available, IPA generation follows this process:

### Option A: EAS Cloud Build (Recommended)

```bash
# 1. Install EAS CLI
npm install -g eas-cli

# 2. Login to Expo
eas login

# 3. Configure project (first time only)
eas build:configure

# 4. Generate IPA via EAS
eas build --platform ios --profile production --non-interactive

# 5. Download IPA from EAS dashboard
# URL: https://expo.dev/accounts/{account}/projects/{project}/builds
```

### Option B: Local Build (Requires macOS)

```bash
# 1. Generate native iOS project
npx expo prebuild --platform ios

# 2. Open Xcode project
open ios/SpiceGarden\ Customer.xcworkspace

# 3. Or build from command line
cd ios
xcodebuild -workspace SpiceGarden\ Customer.xcworkspace \
  -scheme SpiceGarden\ Customer \
  -configuration Release \
  -destination generic/platform=iOS \
  archive -archivePath ./build/SpiceGarden\ Customer.xcarchive

# 4. Export IPA
xcodebuild -exportArchive \
  -archivePath ./build/SpiceGarden\ Customer.xcarchive \
  -exportPath ./build \
  -exportOptionsPlist ExportOptions.plist
```

### Option C: Expo Application Services (EAS) with Custom Native Code

If native iOS modifications are needed (e.g., custom plugins, native modules):

1. Configure `app.config.js` with `expo-build-properties` plugin
2. Add required native dependencies
3. Use EAS Build with custom native code
4. Download IPA from EAS

## Final Launch Recommendation

### Production Load Testing: NOT READY

**Reason:** Current infrastructure (single backend container, 1.5 CPU, 1GB RAM) cannot support production-scale load. At 100 VUs, the system shows 4.15% error rate and 13s p95 latency. The breaking point is approximately 100-150 VUs.

**Required Actions:**
1. Deploy minimum 2 backend replicas with 4 CPU cores each
2. Enable database read replicas
3. Configure Redis Cluster
4. Implement auto-scaling (Kubernetes HPA or AWS ECS)
5. Fix identified backend bugs (ERR_HTTP_HEADERS_SENT, /restaurants/nearby)

### iOS Release: BLOCKED

**Reason:** Both apps are Expo managed workflow projects WITHOUT native iOS code in the repository. IPA generation requires external dependencies (Apple Developer account, certificates, provisioning profiles, EAS project, app icons, splash screens).
